Food Delivery App (Laravel Project)

A web application for managing restaurants, dishes, and orders. Users can browse restaurants, view available dishes, and place orders. Admin users can manage restaurants, dishes, and orders through a dashboard.

Features

Restaurant Listing: Browse all restaurants with images, location, and contact information.

Dish Listing: View all dishes of a selected restaurant with images, descriptions, and prices.

Order Creation: Select a dish, specify quantity, and optionally add notes.

User Dashboard: Registered users can manage their profile and view orders.

Admin CRUD: Full CRUD functionality for restaurants, dishes, and orders.

Responsive Design: Works seamlessly on both desktop and mobile devices.

Interactive Pricing: Automatically calculates total price based on quantity.

Technologies Used

Backend: Laravel PHP Framework

Frontend: Blade Templates, Tailwind CSS, Bootstrap 5

Database: MySQL

Authentication: Laravel Breeze (or Jetstream)

JavaScript: Vanilla JS for interactivity (e.g., dynamic order total)
